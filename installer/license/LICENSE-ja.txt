■ 同梱しているソフトウェア

smarcivaZIP は、圧縮・解凍の処理に 7-Zip の 7z.dll を使っており、これを同梱しています。7z.dll には smarcivaZIP とは別のライセンスが適用されます。

7-Zip (7z.dll)
  著作者    : Igor Pavlov
  配布元    : https://www.7-zip.org/
  ライセンス: GNU LGPL v2.1 以降（一部 BSD 3-clause、および unRAR 制限）
  全文      : インストール先の 7-Zip-License.txt

  7z.dll は改変せず、別ファイルのまま使っています。同じフォルダの 7z.dll を差し替えれば、別のビルドに置き換えられます。ソースコードは上記の配布元から入手できます。

unRAR 制限（7z.dll に含まれる RAR 展開コードについて）
  RAR 形式の展開コードは RARLAB の unRAR ソースに由来し、次の制限があります。

    The unRAR sources cannot be used to re-create the RAR compression algorithm, which is proprietary. Distribution of modified unRAR sources in separate form or as a part of other software is permitted, provided that it is clearly stated in the documentation and source comments that the code may not be used to develop a RAR (WinRAR) compatible archiver.

  このため、smarcivaZIP に含まれるコードを、RAR (WinRAR) 互換のアーカイバを開発するために使うことはできません。
  smarcivaZIP 自身も、RAR 形式は展開のみに対応し、RAR 形式での圧縮は行いません。
