■ Bundled software

smarcivaZIP uses 7z.dll from 7-Zip for compression and extraction, and ships it alongside the application. 7z.dll is under its own license, separate from smarcivaZIP's.

  Author   : Igor Pavlov
  Source   : https://www.7-zip.org/

  Full text: 7-Zip-License.txt in the installation folder

  7z.dll is used unmodified, as a separate file. You can replace it with another build by swapping the 7z.dll in the same folder. Its source code is available from the address above.

unRAR restriction (applies to the RAR extraction code inside 7z.dll)

    The unRAR sources cannot be used to re-create the RAR compression algorithm, which is proprietary. Distribution of modified unRAR sources in separate form or as a part of other software is permitted, provided that it is clearly stated in the documentation and source comments that the code may not be used to develop a RAR (WinRAR) compatible archiver.

  Accordingly, the code included with smarcivaZIP may not be used to develop a RAR (WinRAR) compatible archiver. smarcivaZIP itself only extracts RAR archives; it never creates them.
